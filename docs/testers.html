This page is for the app's admins. Everyone else gets the app from the home page.

A test copy installs next to the real app as “Muhurta Pomodoro Test” (on Android, “Muhurta Test”), keeps its own data on the device, and never updates itself: come back here for newer builds. It syncs with your account like the real app, so what you time in it is real.

Test builds come from the testing branch: each push there makes a new one in about 20 minutes. When one is good, merge testing into main and tag the release as usual.

iPhone has no test copy yet: its app is the website itself, so it always runs the released version.
